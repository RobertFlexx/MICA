# Extensions and profiles

MICA 2.0 adds the 2C compact instruction set to the scalar base and optional
X, M, F, B, T, A and V extensions. The [2.0 specification](architecture/MICA2.md)
defines the delta; the [compatibility manual](architecture/ISA.md) retains
unchanged instructions.
The [profile manifest](../isa/profiles/profiles.json) records supported
configurations, while [SDK status](../SDK_STATUS.md) distinguishes RTL support from
emulator-only implementations and proposed work.
