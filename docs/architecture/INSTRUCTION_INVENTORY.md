# Instruction engineering inventory

Generated from the encoding JSON and disjoint allocation patterns. This describes the ISA 2.0 compatibility baseline of MICA 3.0 development; it adds no opcode. Masks are allocation envelopes in logical parcel order, not complete legality constraints or host byte order. Marginal area and routed timing are unmeasured. Minimum cycles assume an instruction-buffer hit, immediate request acceptance and next-cycle synchronous data response; this is not WCET. Misses, cross-word instructions, stalls, faults and interrupts add cycles.

All scalar entries remain experimental. Assembler selection syntax is separate from hardware: two-operand arithmetic retains its short form; three-operand arithmetic selects short only when registers permit it, otherwise existing ALU3. Explicit add3 and peers retain their long encoding. High-register mov expands to add-with-zero. li selects known small literals; li32/li64 retain explicit object forms. No encoding is deleted or renumbered.
