# Current hardware drawings

Editable DOT sources, SVG previews, PDF previews and an elaborated port manifest are
under `schematics/current`. The generator uses Yosys and rejects missing RTL net
names. Labels contain actual signal names and widths for the default
XLEN32/eight-register elaboration. Rerun with `scripts/generate_schematics.py`;
`--check` validates sources and manifest without rewriting previews.

| Drawing | Information |
| --- | --- |
| [Core ports](../../schematics/current/core-ports.svg) | every port, direction, width and reset/clock context |
| [Datapath](../../schematics/current/datapath.svg) | register reads, ALU result, pending writes, commit and PC |
| [Fetch](../../schematics/current/fetch.svg) | word reuse, parcel selection and instruction handshake |
| [Memory](../../schematics/current/memory.svg) | effective address, byte lanes, held request/response and writeback |
| [SoC peripherals](../../schematics/current/soc-peripherals.svg) | actual SRAM, UART RX/FIFO, CRC VHDL engine and transactional adapter module ports |
| [Traps](../../schematics/current/traps.svg) | pending sources, timer comparison, masks and saved state |

Core drawings group nets by function and FSM phase within `mica_core_txn`.
Labels are checked against the module's elaboration and follow architectural
data flow. The [memory interface](MEMORY_INTERFACE.md) and
[microarchitecture](MICROARCHITECTURE.md) define timing and state transitions;
the [register reference](../architecture/REGISTERS.md) defines reset and writes.

The segmented ALU in `rtl/mica_add64.sv` is a separate experiment. Its low
33-bit result supplies carry to a high 32-bit adder, with upper-operand
isolation during narrow operations. The main 64-bit core uses its conventional
arithmetic path.

Numbered drawings directly under `schematics/` are archived r1 studies. The
`current` directory contains the r2 wiring references. Arty electrical wiring
and vendor sources are recorded in [board connections](BOARD_CONNECTIONS.md).

The RX/CRC-enabled SoC drawing is generated by `scripts/generate_soc_schematic.py`
and has a separate `--check` mode. Unlike the internal functional-region drawings,
its arrows come from actual module port connections. A named net node joins
identical bit vectors; `$` net names identify the SoC's generated decode/response
expressions. The port JSON records clock/reset connections omitted from the
drawing's repeated signal rails.
