# Current hardware drawings

Editable DOT sources, SVG previews, PDF previews and an elaborated port manifest
are under `schematics/current`. The generator uses Yosys and rejects missing
RTL net names. Labels contain actual signal names and widths for the default
XLEN32/eight-register elaboration. Rerun with `scripts/generate_schematics.py`;
`--check` validates sources and manifest without rewriting previews.

| Drawing | Information |
| --- | --- |
| [Core ports](../../schematics/current/core-ports.svg) | every port, direction, width and reset/clock context |
| [Datapath](../../schematics/current/datapath.svg) | register reads, ALU result, pending writes, commit and PC |
| [Fetch](../../schematics/current/fetch.svg) | word reuse, parcel selection and instruction handshake |
| [Memory](../../schematics/current/memory.svg) | effective address, byte lanes, held request/response and writeback |
| [SoC peripherals](../../schematics/current/soc-peripherals.svg) | actual SRAM, UART RX/FIFO, CRC VHDL engine and transactional adapter module ports |
| [Traps](../../schematics/current/traps.svg) | pending sources, timer comparison, masks and saved state |

Nodes describing functions/FSM phases are logical regions within
`mica_core_txn`, not invented module interfaces. DOT nets are checked against
that module's elaboration; arrows are not a transistor-level netlist.
System interfaces and timing are defined in MEMORY_INTERFACE.md and
MICROARCHITECTURE.md. Register reset/write behavior is in the architecture's
REGISTERS.md. The experimental segmented ALU is independently implemented in
`rtl/mica_add64.sv`, with low 33-bit carry feeding a 32-bit high adder and upper
operand isolation for narrow operations. It is not integrated into core64.

Numbered diagrams directly under `schematics/` are archived r1 studies and
must not be used as current wiring references. This project designs no custom
PCB; no invented KiCad board is supplied. Actual Arty electrical connections
are taken from the board vendor and recorded in BOARD_CONNECTIONS.md.

The RX/CRC-enabled SoC drawing is generated by
`scripts/generate_soc_schematic.py` and has a separate `--check` mode. Unlike
the internal functional-region drawings, its arrows come from actual module
port connections. A named net node joins identical bit vectors; `$` net names
identify the SoC's generated decode/response expressions. The port JSON records
clock/reset connections omitted from the drawing's repeated signal rails.
