# CPU hardware

The [reference microarchitecture](hardware/MICROARCHITECTURE.md) describes the
multicycle core. Integration details are in the [memory
interface](hardware/MEMORY_INTERFACE.md), [peripheral map](hardware/PERIPHERALS.md)
and [clock/reset guide](hardware/CLOCK_RESET.md). See the
[drawings](hardware/DATAPATH.md) for signal connections and the [Arty A7
guide](hardware/FPGA_BUILD.md) for the board target.

The [2.0 implementation guide](hardware/MICA2_IMPLEMENTATION.md) covers compact
instructions and WFI. The [verification report](engineering/MICA2_VERIFICATION.md)
records executed checks and the remaining physical measurements.
